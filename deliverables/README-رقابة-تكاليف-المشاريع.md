# حزمة رقابة تكاليف المشاريع — شركة المدن الحديثة

## ما تتضمنه الحزمة

هذه الحزمة تحتوي على مصدر نظام Modern Cities ERP كاملاً، متضمناً وحدة رقابة تكاليف المشاريع، واختبارات API والواجهة.

تتيح الوحدة:

- إعداد خط أساس BOQ لكل مشروع: رمز البند، الوصف، وحدة القياس، الكمية والسعر المخطط.
- تسجيل فواتير الموردين والمستخلصات كسطور مرتبطة ببنود BOQ.
- مقارنة كميات وقيم الفواتير والمستخلصات مع المخطط، على مستوى البند والمشروع.
- التنبيه عند تجاوز الكمية أو القيمة المخططة أو انحراف سعر الوحدة بأكثر من 5%.
- دورة مستندات: مسودة، إرسال للمراجعة، اعتماد أو رفض، وتسجيل المدفوع.
- إلزام المستخدم بكتابة مبرر قبل اعتماد مستند عليه انحرافات، وسبب عند الرفض.
- تثبيت بند BOQ بعد ربطه بمستندات للمحافظة على أثر المراجعة؛ تسجل التغييرات كبنود مستقلة.

المسار داخل التطبيق: `/re/cost-control`.

## تشغيل نسخة التطوير

المتطلبات: Node.js 22 أو أحدث بسبب استخدام `node:sqlite`.

```bash
npm install
npm --prefix web install
npm run dev
```

افتح واجهة التطوير على المنفذ 5173. بيانات الدخول في قاعدة العرض التجريبية:

- البريد: `admin@noor.iq`
- كلمة المرور: `admin123`

غيّر أو عطّل بيانات الدخول التجريبية قبل أي استخدام إنتاجي.

## ملاحظات تشغيلية مهمة

- الوحدة مدمجة في تطبيق مستقل مبني بـ React وExpress وSQLite؛ **ليست إضافة Odoo جاهزة** ولا تثبّت مباشرة في Odoo.
- مستندات الرقابة لا تنشئ قيوداً محاسبية تلقائياً في هذه النسخة، لتجنب تكرار احتساب الفاتورة والمستخلص لنفس العمل. راجع التنبيه داخل واجهة الوحدة.
- عند نشر التطبيق المستقل، اجعل `DATA_DIR` على قرص دائم وخذ نسخاً احتياطية منتظمة.
- لا تشغّل `npm run seed -- --force` على قاعدة بيانات إنتاجية؛ هذا الأمر يعيد تهيئة بيانات التطبيق.
- لنشرها داخل Odoo، يجب تحويل الوظائف إلى إضافة Odoo متوافقة مع إصدار Odoo المستهدف، ثم اختبارها على نسخة مرحلية قبل الإنتاج.
