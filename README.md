# نور ERP — نظام إدارة مشاريع وموارد مؤسسية متكامل

نظام ERP عربي بالكامل (RTL) مبني حول **المشاريع** كنواة تربط المبيعات والمشتريات والمخزون والمحاسبة والموارد البشرية في دورة واحدة متكاملة.

- **الواجهة:** React 18 + TypeScript + Vite (تصميم مخصص بخط Tajawal / IBM Plex Sans Arabic)
- **الخلفية:** Node.js + Express 4 + `node:sqlite` (بدون أي تبعيات قاعدة بيانات خارجية)
- **الإصدار:** 2.0.0 · **العملة:** دينار عراقي (د.ع) · **الضريبة:** 15%

---

## 1. التشغيل السريع

```bash
npm install                # تبعيات الخادم
npm --prefix web install   # تبعيات الواجهة
npm run seed               # بيانات عرض لبيئة تطوير جديدة فقط؛ لا يمس قاعدة مهيأة
npm run dev                # خادم API على 4000 + واجهة Vite على 5173
```

ثم افتح: `http://localhost:5173`

> **تحذير لحماية البيانات:** أمر `npm run seed` لا يعيد تهيئة قاعدة تحتوي مستخدمين قائمين.
> الخيار `--force` ممنوع افتراضياً ولا يعمل إلا في قاعدة تجريبية معزولة
> عند ضبط `ALLOW_DESTRUCTIVE_SEED=I_ACKNOWLEDGE_DELETION` بصورة مقصودة.
> يمنع تنفيذ أي تهيئة لبيانات العرض عند `NODE_ENV=production`،
> كما يرفض الخادم بدء قاعدة إنتاجية جديدة بمستخدمين تجريبيين افتراضيين.
> هذا التطبيق مستقل عن Odoo؛ لا تستورد بياناته التجريبية إلى قاعدة المدن الحديثة.

## 3. التكامل بين الوحدات

```
عرض سعر ──تحويل──▶ فاتورة ──دفعة──▶ قيد تحصيل ──▶ ذمم/نقد
     │                  │
     └── مربوط بمشروع ───┴──▶ إيراد المشروع وربحيته

أمر شراء ──استلام──▶ حركة مخزون ──▶ قيمة المخزون + قيد الالتزام على المورد
مشروع ──تكلفة منفذة──▶ مصروف محاسبي ──▶ ربحية المشروع
موظف ──كشف راتب──▶ مصروف الرواتب + صافي المستحق
```

كل عملية مالية تُنتج **قيداً يومياً متوازناً** تلقائياً، ولذلك تبقى ميزان المراجعة والميزانية العمومية متوازنة دائماً (يتم التحقق من ذلك في الاختبارات).

## 6. قرارات تصميمية

- **العربية أولاً:** كل النصوص والأرقام والتواريخ بصيغة عراقية مع أرقام لاتينية متناسقة (`ar-IQ-u-nu-latn`).
- **الطاولات الكثيفة:** كل قائمة تعرض معلومات مركّبة (عميل، مشروع، حالة، مبالغ، تواريخ) دون الحاجة لفتح السجل.
- **لوحة أوامر:** `Ctrl/⌘ + K` للتنقل والبحث الفوري في المشاريع والعملاء والفواتير.
- **الطباعة:** قوالب فاتورة/عرض سعر/أمر شراء قابلة للطباعة بتنسيق مستند رسمي.
- **الصلاحيات:** أدوار (admin / manager / accountant / hr / viewer) تحكم الوصول للوحدات والعمليات.
- **المتانة:** حدود أخطاء في الواجهة، تحقق من المدخلات في الخادم، ومعاملات (transactions) للعمليات المالية.
